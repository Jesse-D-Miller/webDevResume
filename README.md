# Web Dev Resume

A modern React + Vite portfolio/resume site with an alternate “cyber” presentation and interactive sections. My Idea with this project was to create a fun and interactive experience that serves as both my resume and my portfolio. 

## Highlights
- Cyber/standard themes
- Interactive resume sections and XP-style micro‑interactions
- Optional “Secret Resume” view
